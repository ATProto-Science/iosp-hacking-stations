Two patches, one substrate

Patch 1

Keys → Board

A browser interaction — a key, a scrub, a wavefold, an FM sweep — becomes a real, signed music.atproto.noizetoyz.synth.note record. A relay watches the network for it and re-broadcasts it live; a Wemos D1 mini running Mozzi turns it into one of six real synthesis techniques and draws the note name and a decaying waveform on its OLED — same room, same second.

Patch 2

Sensor → Feed

A BMP180 temperature/pressure sensor — with a DHT22 humidity sibling — on the same boards writes into Live Data Streaming's existing sensor-reading collection over WiFi. No separate backend, same substrate, read back out through the live readout above.
